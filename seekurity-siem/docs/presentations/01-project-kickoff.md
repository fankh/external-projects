# 3. 추진 일정

## 전체 일정 (약 18주)

```
Phase 1: 준비 (2주)     ████
Phase 2: 설계 (3주)     ██████
Phase 3: 구축 (5주)     ██████████
Phase 4: 테스트 (4주)   ████████
Phase 5: 안정화 (4주)   ████████
```

| Phase | 기간 | 주요 활동 |
|-------|------|----------|
| 준비 | 2주 | Kickoff, 환경 분석, 요구사항 정의 |
| 설계 | 3주 | 아키텍처 설계, Log Source 설계, 탐지 시나리오 설계 |
| 구축 | 5주 | 서버 설치, 연동, 룰 개발 |
| 테스트 | 4주 | 단위/통합/성능 테스트 |
| 안정화 | 4주 | 운영 이관, 교육, 안정화 |
