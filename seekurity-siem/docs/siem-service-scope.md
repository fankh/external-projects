# Seekurity SIEM 구축비 및 유지보수 서비스 범위

---

## 1. 구축비에 포함되는 사항

기존 견적서상 '아키텍처 컨설팅'으로 기재된 항목에 대해, KOVAN 프로젝트 수행 경험을 바탕으로 세부 제공 항목을 아래와 같이 정리합니다.

### 1.1 사전 분석 및 컨설팅

| 항목 | 세부 내용 |
|------|-----------|
| 현황 분석 | 고객사 보안 인프라 현황 파악 (네트워크 구성, 보안 장비 목록, 기존 로그 관리 체계 등) |
| 요구사항 정의 | 고객사 보안 모니터링 요구사항 수집 및 정의 (탐지 시나리오, 대시보드, 리포트 등) |
| Log Source 목록 확정 | 연동 대상 시스템 식별 및 우선순위 결정 (방화벽, VPN, IDS/IPS, EDR, DLP, NAC 등) |
| 관련 담당자 인터뷰 | 보안 운영, 네트워크, 시스템 담당자 대상 인터뷰 수행 |

### 1.2 아키텍처 설계

| 항목 | 세부 내용 |
|------|-----------|
| SIEM 아키텍처 설계 | 고객사 환경에 최적화된 SIEM 서버 구성 설계 (Manager, Collector, Storage 등) |
| 네트워크 설계 | SIEM 연동을 위한 네트워크 구간 설계 및 방화벽 정책 수립 |
| 용량 산정 | 일일 로그 수집량 기반 Storage, 메모리, CPU 등 HW 스펙 산정 |
| HA/DR 설계 | 고가용성 및 재해복구 방안 설계 (필요 시) |
| 로그 수집 경로 설계 | Protocol별 수집 경로 설계 (Syslog, SNMP, Agent, API) |

### 1.3 구축 및 연동

| 항목 | 세부 내용 |
|------|-----------|
| Seekurity SIEM 설치 | Manager, Collector, 관련 컴포넌트 설치 및 초기 설정 |
| Log Source 연동 | 대상 장비별 로그 수집 설정 및 수신 검증 |
| Parser 개발 | 로그 포맷별 Parser 개발 및 정규화(Normalization) 처리 |
| 방화벽 정책 요청 | SIEM 연동을 위한 방화벽 오픈 정책 정리 및 요청서 작성 |

### 1.4 탐지 룰 및 대시보드 구성

| 항목 | 세부 내용 |
|------|-----------|
| 탐지 시나리오 설계 | MITRE ATT&CK 기반 탐지 룰 설계 (고객사 환경에 맞는 시나리오 선정) |
| 탐지 룰 구현 | 설계된 시나리오 기반 탐지 룰 생성 및 테스트 |
| 대시보드 구성 | 보안 모니터링 대시보드 구성 (실시간 현황, 탐지 현황, 트래픽 현황 등) |
| 리포트 템플릿 | 일간/주간/월간 보안 리포트 템플릿 구성 |
| 알람 설정 | Email, Slack 등 알람 채널 연동 및 알림 조건 설정 |

### 1.5 테스트 및 검증

| 항목 | 세부 내용 |
|------|-----------|
| 연동 검증 (FVT) | 전체 Log Source 수신 상태 검증 |
| 탐지 테스트 | 탐지 룰 동작 검증 및 오탐/미탐 조정 |
| 성능 테스트 | 로그 수집 처리량, 검색 성능 등 기준치 달성 여부 확인 |
| 사용자 기능 확인 | 고객사 보안 운영자 대상 기능 검증 |

### 1.6 교육 및 기술 이전

| 항목 | 세부 내용 |
|------|-----------|
| 운영자 교육 | SIEM 운영 교육 (로그 검색, 탐지 룰 관리, 대시보드 활용 등) |
| 관리자 교육 | 시스템 관리 교육 (사용자 관리, 백업/복구, 성능 모니터링 등) |
| 운영 매뉴얼 제공 | 운영/관리 매뉴얼 및 장애 대응 가이드 제공 |

### 1.7 산출물

| 산출물 | 형식 |
|--------|------|
| 프로젝트 수행 계획서 | PPT/PDF |
| SOW (작업명세서) | XLSX |
| 요구사항 정의서 | XLSX |
| 로그 연동 설계서 (Log Source 목록) | XLSX |
| 방화벽 정책 요청서 | XLSX |

| 탐지 시나리오 정의서 | XLSX |

## 2. 유지보수 범위 (상세)

첫 해(구축 연도) 이후 제공되는 유지보수 서비스 범위는 아래와 같습니다.

### 2.1 유지보수 지원 항목

| 구분 | 지원 항목 | 세부 내용 |
|------|-----------|-----------|
| SW 유지보수 | Seekurity SIEM 업데이트 | 보안 패치, 버그 수정, 마이너 버전 업그레이드 제공 |
| SW 유지보수 | 탐지 룰 업데이트 | 최신 위협 기반 탐지 룰 패키지 업데이트 제공 |
| SW 유지보수 | 위협 인텔리전스 업데이트 | TI Feed 업데이트 (IoC, IP Reputation 등) |
| 기술 지원 | 기술 문의 대응 | 운영 중 발생하는 기술 문의 원격 대응 |
| 기술 지원 | Log Source 추가 연동 | 신규 장비/시스템 추가 연동 지원 (연 N건, 협의) |
| 기술 지원 | Parser 수정/개발 | 로그 포맷 변경 시 Parser 수정 또는 신규 개발 |
| 기술 지원 | 탐지 룰 튜닝 | 오탐/미탐 조정 및 신규 탐지 시나리오 추가 (협의) |
| 시스템 관리 | 시스템 상태 점검 | 정기 점검 시 시스템 리소스, 프로세스 상태, 인덱스 상태 확인 |
| 시스템 관리 | 백업 점검 | 설정 백업 및 데이터 보존 정책 점검 |

### 2.2 대응 범위 및 수준

| 구분 | 내용 |
|------|------|
| 장애 대응 | SIEM 시스템 장애 발생 시 원격 진단 및 복구 지원 |
| 장애 대응 SLA | 접수 후 4시간 이내 초기 대응 (원격), 중대 장애 시 익영업일 내 방문 대응 |
| 기술 지원 | 운영 중 발생하는 설정 변경, 기능 문의, 연동 이슈 등 기술 상담 |
| 기술 지원 채널 | 이메일, 전화, 원격접속 (VPN/TeamViewer 등) |
| 기술 지원 시간 | 평일 09:00 ~ 18:00 (공휴일 제외) |
| 긴급 장애 | 서비스 중단급 장애 시 24시간 긴급 대응 (별도 협의) |

### 2.3 정기/비정기 지원

| 구분 | 주기 | 내용 |
|------|------|------|
| **정기 점검** | 월 1회 | 시스템 상태 점검, 성능 리뷰, 디스크/인덱스 관리, 업데이트 적용 |
| **정기 리포트** | 월 1회 | 점검 결과 보고서 제공 (시스템 현황, 탐지 통계, 개선 권고) |
| **비정기 지원** | 수시 | 장애 발생, 긴급 기술 문의, Log Source 추가 등 요청 시 대응 |
| **비정기 지원** | 수시 | 보안 이벤트 발생 시 탐지 룰 긴급 추가/수정 |

### 2.4 상주/비상주 및 대면 지원

| 구분 | 기본 제공 | 비고 |
|------|-----------|------|
| **기본 운영 형태** | 비상주 (원격) | 이메일, 전화, 원격접속을 통한 지원 |
| **정기 방문** | 월 1회 방문 | 정기 점검 및 대면 미팅 (점검 보고서 제공) |
| **장애 방문** | 원격 해결 불가 시 방문 | 중대 장애 발생 시 방문 대응 (SLA 기준 적용) |
| **상주 지원** | 별도 계약 | 상주 엔지니어 파견 필요 시 별도 비용 협의 |
| **추가 방문** | 별도 협의 | 정기 방문 외 추가 방문 요청 시 별도 비용 발생 가능 |

### 2.5 HW 구매 방식에 따른 유지보수 구분

| 구분 | 고객 직접 HW 구매 | HW 공급 포함 (일괄 납품) |
|------|-------------------|--------------------------|
| **SW 유지보수** | 포함 (동일) | 포함 (동일) |
| **SW 업데이트** | 포함 (동일) | 포함 (동일) |
| **HW 장애 대응** | 제외 — 고객이 HW 벤더에 직접 A/S 요청 | 포함 — HW 장애 접수 및 교체 대행 |
| **HW 보증 관리** | 제외 — 고객이 HW 벤더 보증 계약 별도 관리 | 포함 — 보증 기간 내 무상 교체, 보증 만료 후 유상 |
| **디스크 교체** | 제외 — 고객이 HW 벤더에 디스크 교체 요청, SIEM 측은 교체 후 볼륨 재구성 및 데이터 복구만 지원 | 포함 — 장애 디스크 교체 대행 및 SIEM 볼륨 재구성, 데이터 복구까지 일괄 처리 |
| **디스크 증설** | 제외 — 고객이 직접 HW 조달 후 SIEM 설정 변경만 지원 | 포함 — 증설 필요 시 HW 조달 및 SIEM 연동까지 일괄 처리 |
| **파워 서플라이 교체** | 제외 — 고객이 HW 벤더에 PSU 교체 요청, SIEM 측은 교체 후 시스템 정상 기동 확인만 지원 | 포함 — PSU 장애 접수, 교체 대행 및 시스템 정상 기동 검증까지 일괄 처리 |
| **OS/인프라 지원** | 제한적 — SIEM 운영에 영향을 미치는 OS 이슈에 한해 지원 | 포함 — OS 패치, 설정 변경 등 인프라 레벨 지원 |
| **유지보수 비용** | SW 유지보수 비용만 청구 | SW + HW 유지보수 비용 통합 청구 |

> **참고**: 고객이 HW를 직접 구매한 경우에도 SIEM SW의 안정적 운영을 위해 HW 장애(디스크, 파워 서플라이 등) 발생 시 진단 협조(로그 확인, 원인 분석, 장애 부품 식별)는 제공합니다. 단, 부품 교체/수리 자체는 HW 벤더의 책임이며, 교체 완료 후 SIEM 시스템 정상화(볼륨 재구성, 서비스 기동 확인 등) 작업은 지원합니다.
