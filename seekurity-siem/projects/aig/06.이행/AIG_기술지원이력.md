|---|---|
| 1 | 프런트엔드가 선택 필드 `timeFormat` 에 방어 없이 `.trim()` 을 호출 (TS-015) |
| 2 | `InfraCollector` 엔티티가 nullable 컬럼을 primitive 로 매핑해, 한 행의 NULL 로 목록 조회 전체가 500 실패 (TS-009) |
| 3 | 기본 룰 마이그레이션 SQL 이 `ON CONFLICT (uuid)` 를 사용하나 배포 스키마에 해당 유니크 제약이 없음 (TS-017) |
| 4 | 기본 룰이 참조하는 `deviceAction` 필드가 제품 어디에서도 생성되지 않음 (TS-018) |
| 5 | `ss-syslog-receiver` 로그 파일이 `root:root` 로 생성되어 `seekurity` 계정 서비스가 기록 불가 |
| 6 | 탐지 엔진이 `rule_conditions` 를 적용하지 않는 것으로 관측됨. 조건 없이 임계치만으로 발화 (TS-019) |
| 7 | 탐지 화면의 건수와 목록이 다른 기준으로 조회되어, 참조 룰이 삭제된 이력에서 값이 어긋남 (TS-020) |
