## 3. 알람 대응 절차

### 3.1 심각도별 SLA

| 심각도 | 채널 | 대응 SLA |
|--------|------|----------|
| **CRITICAL** | Email + SMS | 15분 내 1차 대응 |
| **HIGH** | Email + Slack | 1시간 내 분석 |
| **MEDIUM** | Slack | 4시간 내 확인 |
| **LOW** | 대시보드 | 익영업일 검토 |

### 3.2 대응 흐름

1. 알람 수신 → SIEM Web UI 로그인 → 상세 확인
2. 룰 ID 기준 `workbooks/KOVAN_탐지룰목록.xlsx` 참조 → 대응 가이드 확인
3. 침해 의심 시: 격리 → 분석 → 보고
4. 조치 결과 기록 (티켓 시스템)

## 4. 검색 / 분석

### 4.1 기본 검색

- 메뉴: 검색
- Free-Text: 키워드 직접 입력
- Field 검색: `src_ip:1.1.1.1 AND action:deny`
- 시간 범위: Last 1h / 24h / 7d / Custom

### 4.2 자주 쓰는 쿼리

| 목적 | Query |
|------|-------|
| 로그인 실패 | `event_type:auth_fail` |
| 외부 통신 | `dst_ip:NOT(internal_subnet)` |
| 차단 트래픽 | `action:deny` |
| VPN 해외 접속 | `event_type:vpn_login AND src_country:NOT KR` |

## 5. 룰 관리

### 5.1 신규 룰 생성

1. `관리 > 탐지 룰 > 신규 추가`
2. Rule 명 / 설명 / 심각도 입력 (Naming: `[심각도]_[대상]_[행위]`)
3. 탐지 조건 (Query / Pseudo Code) 작성
4. MITRE ATT&CK Tactic / Technique 매핑
5. 알람 채널 / 수신자 설정
6. 테스트 → 활성화

### 5.2 기존 룰 튜닝

- 오탐 발생 시: 예외 조건 추가 (whitelist)
- 미탐 발생 시: 조건 완화 (임계치 조정)
- 비활성화 → 30일 후 삭제

## 7. 사용자 / 백업 / 장애 대응

### 7.1 사용자 추가

`관리 > 사용자 > 신규 추가` — ID/Email/부서/역할 입력

**비밀번호 정책**: 최소 12자 / 영문 대소문자+숫자+특수문자 / 90일 주기 변경 / 최근 5개 재사용 금지

### 7.2 백업 정책
