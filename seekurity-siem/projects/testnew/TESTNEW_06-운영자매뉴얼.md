## 3. 알람 대응

### 3.1 알람 수신 시 절차

1. 알람 내용 확인 (Email / Slack / SMS)
2. SIEM Web UI 로그인 후 상세 확인

### 3.2 심각도별 대응 SLA

| 심각도 | 초기 대응 | 보고 |
|--------|-----------|------|
| Critical | 15분 | 즉시 |
| High | 1시간 | 일일 보고 |
| Medium | 4시간 | 주간 보고 |
| Low | 익영업일 | 월간 보고 |

## 4. 검색 / 분석

### 4.1 기본 검색

```
Web UI > 검색
- Free-Text: 키워드 검색
- Field 검색: src_ip:1.1.1.1 AND action:deny
- 시간 범위: Last 1h / 24h / 7d / Custom
```

### 4.2 고급 검색

- 정규식 (`/regex/`)
- 집계 (count, group by)
- Saved Search 관리

### 4.3 자주 쓰는 검색 쿼리

| 목적 | Query 예시 |
|------|------------|
| 로그인 실패 | `event:auth_fail` |
| 외부 통신 | `dst_ip:NOT(internal_subnet)` |
| 차단 트래픽 | `action:deny` |

## 5. 룰 관리

### 5.1 신규 룰 생성

1. `관리 > 탐지 룰 > 신규 추가`
2. Rule 명 / 설명 / 심각도 입력
3. 탐지 조건 (Query / Pseudo Code) 작성
4. 알람 채널 / 수신자 설정
5. 테스트 → 활성화

### 5.2 기존 룰 수정 / 비활성화

- 오탐 발생 시: 예외 조건 추가
- 미탐 발생 시: 조건 완화
- 폐기: 비활성화 후 30일 후 삭제
