# 적대 감사 후속조치 (미조치 잔여 항목)

v1.5.x 에서 9개 핵심 서브시스템(결재·영속화·SR/변경·컴플라이언스·재무·보안의식·인프라·
게시판/설정, 그리고 직전 델타)을 적대적으로 감사해 확정 결함을 전수 수정했다. 아래는 감사가
찾았으나 **의도적으로 미조치로 남긴** 항목이다 — 대부분 병렬 피처 트랙이 활발히 편집 중인
알림/할일(todo·notify) 도메인이거나, 데이터 모델 변경이 필요한 사안이다. 각 항목은 낮은
심각도이며 상태 불일치·데이터 손상이 아니라 알림/가시성/정합성 성격이다.

수정 시 해당 도메인 담당(피처 트랙)과 조율하거나, 데이터 모델 변경은 별도 결정으로 진행한다.

| 1 | `app/(app)/work/approvals/actions.ts` (SR 신청 승인 블록) | SR 신청 승인 시 상태만 `CI배정`으로 바꾸고 `'SR 처리'` 할일을 만들지 않는다. 해당 할일 유형은 시드에만 있고 `assignCi`(`sr/ci`)가 닫으려 시도 — 반쪽 루프. | 저 | 할일/알림 도메인(피처 트랙 v1.246~ 활발히 편집).
