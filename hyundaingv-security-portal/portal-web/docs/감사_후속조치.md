# 적대 감사 후속조치 (미조치 잔여 항목)

v1.5.x 에서 9개 핵심 서브시스템(결재·영속화·SR/변경·컴플라이언스·재무·보안의식·인프라·
게시판/설정, 그리고 직전 델타)을 적대적으로 감사해 확정 결함을 전수 수정했다. 아래는 감사가
찾은 저심각·잠재 항목의 처리 현황이다. 전부 상태 불일치·데이터 손상이 아니라 알림/가시성/
정합성 성격이며, portal-web 은 본 트랙 단독 소유다(병렬 v1.24x~ 트랙은 별개 프로젝트
`seekerslab-itam/itam-web` 소속으로 portal-web 파일을 건드리지 않는다).

**#1~#5 전부 조치 완료(v1.5.31·v1.5.33·v1.5.32·v1.5.35·v1.5.36).** #2 타임스탬프 승격은
v1.5.24 프로젝트 과다계수 회귀 테스트까지 가능케 해 실증했고(v1.5.34), #4 는 비-일반 양식
개정 재서약 통지를 일반과 동일하게 확장했다. #5 는 개인 폐기 상신이 부서 취합('취합') 할일을
닫지 않도록 방어(휴면이나 실데이터 대비). **적대 감사 9종 + 후속조치 5종 전부 종결.**
