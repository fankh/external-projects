# 릴리스 노트 — portal-web v1.5.193

이 릴리스는 QnA 폐쇄 루프(v1.5.184~186)가 남긴 **고아 할일 결함**을 고친다. 담당이 지정된 미답변 문의를
삭제하면, 담당 지정 때 만들어진 답변 할일이 담당자의 나의 할일에 영구히 남았다. 답변·재지정만이 그 할일을
닫는데 삭제로 문의 자체가 사라지면 두 경로가 모두 막혀, 닫을 수 없는 고아가 됐다. 3차 정찰이 적발했다.

## 주요 변경

### 문의 삭제 시 답변 할일 마감
`deleteQna` 가 문의·첨부만 정리하고 `assign` 이 만든 QnA 답변 할일은 건드리지 않던 것을, 삭제 시 해당
문의 id 선두 고정으로 담당의 답변 할일을 함께 닫도록 했다(`answer`·재지정과 동일한 앵커드-클로즈 규약).
아울러 삭제의 revalidate 를 `/board/qna` 에서 `/` 레이아웃으로 넓혀, 나의 할일 집계가 즉시 반영된다.

**결함 경로.** assign → 담당의 `${id} 답변` 할일 생성. 이 할일을 닫는 코드는 answer()·재지정뿐이고, 둘 다
문의 row 존재를 전제한다. 그래서 작성자(미답변 본인) 또는 Admin 이 문의를 삭제하면, 할일이 어떤 경로로도
닫히지 않아 담당의 미처리·기한경과 집계를 영구히 부풀렸다(바로가기도 사라진 문의로 연결되는 막다른 길).

## 호환성·영향
- 무회귀: 삭제 시 QnA 할일만 추가로 닫는다. 다른 할일·문의 동작 불변. 저장 스키마 변경 없음.
- 폐쇄 루프 완결: 이제 QnA 할일은 답변·재지정·삭제 세 경로 모두에서 정확히 닫힌다.
