# 릴리스 노트 — portal-web v1.5.295

**실동작 REST 보안관제 어댑터 — 탐지 이벤트 → 보안위반 자동 편입.** 보안관제(SIEM·DLP·EDR) 연동을
목업이 아닌 실제 HTTP 조회로 구현하고, 탐지 유형을 포털 위반 유형으로 정규화해 보안위반으로 자동
편입한다. 메시징·HR·자산에 이은 네 번째 실 어댑터.

## 배경 — 발견 경위

요구사항 보안위반: 보안관제 탐지 이벤트(DLP·EDR·이상행위)를 보안위반으로 자동 등록. 계약
(`SecMonAdapter.fetchEvents`)·자동 편입 로직(`lib/secmon.ts`)은 있었으나 구현이 목업뿐이었다. 실 조회
경로를 채운다.

## 주요 변경
- `lib/integrations/rest.ts`: `restSecmon` 추가 — `PORTAL_SECMON_API_URL` GET 으로 탐지 이벤트 조회,
  `SecurityEvent{name,dept,type,detail,detectedAt}` 매핑. 고객 스키마는 통용 필드명으로, **탐지 유형은
  포털 위반 유형 3종으로 정규화**(USB·이동식 저장장치→'인가되지 않은 USB 사용', 화면잠금·세션→'화면
  미잠금', 출력·프린터→'출력물 방치'). 발생일이 타임스탬프면 날짜로 절단. 인증 `PORTAL_SECMON_API_TOKEN`.
  미설정 시 빈 배열(자가진단 통과), 비정상 응답은 throw(`secmon.ts` try/catch 흡수). 코드에 없는 유형은
  `secmon.ts` 가 드롭(shape 은 어댑터, code 는 편입 지점).
- `lib/integrations/registry.ts`: `rest-secmon` 등록 + 샘플 고객사 보안관제(`fin-secmon`·`gov-secmon`)을
  목업 → 실 REST 재바인딩. 데모 기본(`mock-secmon`)은 유지(결함주입 e2e 불변).

## 호환성·영향
- 무회귀: 데모 기본 프로필은 목업 유지(secmon 결함주입·이관 e2e 불변). 자가진단은 미설정 시 빈 조회로
  통과(secmon 계약은 빈 배열 허용). sec-monitor 채널은 기본 off — 실 배포에서 채널 ON + 엔드포인트 설정 시 동작.
