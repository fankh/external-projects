# 릴리스 노트 — portal-web v1.5.279

**신규 도메인 — 재해복구·업무연속성 관리대장(ISMS 2.12).** 핵심 업무·시스템의 복구목표(RTO/RPO)와 주기적
복구훈련을 관리하고, 훈련 예정일 경과를 추적해 정기 복구훈련을 강제한다. 위험관리대장 시드가 지목했던
'재해복구 체계 부재'(RK-2026-04) 갭을 정식 도메인으로 닫는다.

## 배경 — 발견 경위

정보보호 위험평가 시드에 '재해복구(DR) 체계 부재'가 고위험으로 등록돼 있었으나, 그 위험을 관리하는 실제
BCP/DR 관리대장은 없었다. ISMS 2.12(재해복구)는 핵심 업무의 복구목표(RTO/RPO)를 정의하고 주기적 복구훈련을
실시·기록하도록 요구한다. 정책 재검토 주기와 동형(주기적 이행 강제)이되, 대상은 '복구 훈련'(RTO/RPO·훈련
결과)이라 별도 도메인으로 구현한다.

## 주요 변경
- `lib/types.ts` `DrPlan`(대상·등급·RTO/RPO·담당·훈련주기·최근훈련일·최근결과) + `DrTier`(핵심·중요·일반)·
  `DrTestResult`(미실시·성공·부분성공·실패).
- `lib/dr.ts`(신규 단일 원천): `nextTestDue`(=최근훈련일+주기, 파생)·`isTestOverdue`(예정일 경과)·
  `computeDrKpis`(전체·훈련경과·미실시·최근 실패/부분). lib/dates addMonths 재사용(정책과 공유).
- `app/(app)/compliance/dr/page.tsx`(신규): 관리대장(훈련경과·미실시·실패 우선 정렬) + 등록/복구훈련 기록
  (결과+최근훈련일 갱신, 담당 재직자 재배정)/삭제. 등급·RTO/RPO 표시.
- `lib/store.ts`: `drPlans` 컬렉션 + 시드 3건(ERP 핵심·영업 중요[훈련 경과]·그룹웨어 일반[미실시]).
  `components/chrome/menus.ts`: 보안 컴플라이언스 그룹에 `재해복구·업무연속성`(BIZ).
- `lib/audit.ts`·`settings/audit`: `복구계획 등록·변경·삭제` 감사 액션 + ACTION_TONE. `export` dr-plans 엑셀.
- 게이트 등록(emptystate·health·smoke).

## 호환성·영향
