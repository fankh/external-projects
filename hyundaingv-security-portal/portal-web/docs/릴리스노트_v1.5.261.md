# 릴리스 노트 — portal-web v1.5.261

정보보호 위험평가(v1.5.259)의 **폐쇄 루프를 완성**한다. 일일 알림 배치에 7번째 유형 '위험 조치 지연'을
더해, 조치기한이 지난 미종결 위험의 담당에게 안내메일이 나가도록 한다. 위험 등록·평가는 있으나 조치
독촉이 없어 기한 경과 위험이 방치되던 갭을 닫는다.

## 배경 — 발견 경위

v1.5.259 로 위험관리대장을 추가했으나, 위험은 `dueDate`(조치기한)를 갖는데 그 경과를 담당에게 상기시키는
경로가 없었다. 포털의 일일 알림 배치는 이미 기한 경과·미이행 항목(SR 지연·점검 경과·확인서 미제출 등 6종)을
스캔해 담당에게 통지하는 폐쇄 루프를 운영한다. 위험 조치 기한 경과는 정확히 이 배치가 다루는 '기한 경과
미이행'이라, 7번째 유형으로 편입해 위험처리 루프(식별→평가→조치→종결)의 마지막 고리(조치 독촉)를 잇는다.

## 주요 변경
- `lib/notify.ts`: 일일 배치에 7) '위험 조치 지연' 추가 — 미종결(`!isRiskClosed`) + 조치기한 경과(`dueDate < today`)
  위험의 담당에게 안내. 종결(완료)하면 자동 제외. **재직자 교집합**(`.filter((name) => people.some(...))`)으로
  담당이 퇴사해 s.people 에서 빠지면 유령 독촉을 막는다 — SR 지연·확인서 미제출 등 타 person 알림과 동일
  정합. 지연 술어는 `dueDate < t` 문자열 비교(위험관리대장 KPI·sr 지연·산출물 기한경과와 동일).

## 호환성·영향
- 무회귀: 기존 6종 알림·집계 불변. 신규 유형은 대상이 있을 때만 결과에 포함(0명이면 배치 감사에 미표기,
  기존 send() 동작과 동일). 위험 자체는 위험관리대장에 남아 미조치 가시성은 유지된다.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · **e2e 99**(신규 sc_risk_overdue_notify).
- `sc_risk_overdue_notify`(격리): 조치기한 경과 미종결 위험 2건(담당 재직 김현우·퇴사 E2E퇴사담당) →
  알림 배치 '위험 조치 지연' 대상이 **재직 1명**(퇴사 담당 제외)임을 감사 상세로 검증. 재직 교집합 제거 시
  '2명'으로 단언 실패함을 실측 대조(fails-without-fix). 기존 6종(미서약·점검 경과·SR 지연·재택·확인서)과 병행 발화 확인.
