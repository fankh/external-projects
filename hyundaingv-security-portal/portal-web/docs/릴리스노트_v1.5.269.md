# 릴리스 노트 — portal-web v1.5.269

정보보호 위험평가 도메인에 **위험 추세 스냅샷**을 더한다. 주기(월)별 위험 KPI 를 기록해 위험 감소 추이
(ISMS '전기 대비 개선')를 본다 — 컴플라이언스 포스처 추세 스냅샷과 대칭. 위험 등록·평가·조치는 있었으나
'개선되고 있는가'를 보여주는 추이가 없던 갭을 닫는다.

## 배경 — 발견 경위

위험평가 도메인(v1.5.259~267)은 현재 위험 현황(등록·평가·조치·종결)은 다루나, ISMS 인증이 중시하는
'전기 대비 개선 추이'(위험 감소 증빙)가 없었다. 포털은 이미 컴플라이언스 포스처를 주기별 스냅샷으로 쌓아
추세를 보이는데(complianceSnapshots·추세 export), 위험 KPI(미종결·높음↑·경과·종결률)도 같은 방식으로
스냅샷을 쌓으면 위험 감소 추이를 감사 근거로 제시할 수 있다. 포스처 스냅샷 인프라를 그대로 대칭 적용한다.

## 주요 변경
- `lib/types.ts` `RiskSnapshot`(period·total·open·highOpen·overdue·treatedRate) — ComplianceSnapshot 대칭.
- `lib/risk.ts` `upsertRiskSnapshot(s, by)`: 당월(YYYY-MM) 위험 KPI 스냅샷 upsert(월 1건 유지·값 refresh) —
  수동·일배치 공용 단일 경로(upsertComplianceSnapshot 대칭).
- `lib/store.ts` `riskSnapshots` 컬렉션 + 시드 2건(2026-06·07, 높음↑ 5→4 감소 추이).
- `app/(app)/compliance/risks/page.tsx`: '위험 추세' 카드(주기별 표 + 높음↑ 미종결 증감 ▼/▲ 신호) +
  '현황 스냅샷 기록' 버튼(BIZ_MGR·ADMIN).
- `lib/notify.ts`: 일배치 0-d 위험 추세 스냅샷 자동 기록(컴플라이언스 스냅샷 0-b 대칭 — 사람 손 없이 추이 축적).
- `app/api/export/route.ts`: `risk-trend` 엑셀(위험 추세, BIZ 게이트) + EXPORT_MENU 등록.
- `lib/audit.ts`·`settings/audit`: `위험 스냅샷` 감사 액션 + ACTION_TONE.

## 호환성·영향
- 무회귀: 기존 위험평가 화면·KPI·알림 불변. 위험 추세는 신규 카드/컬렉션 추가로, riskSnapshots 는 시드-머지
  제네릭 경로가 자동 정규화(수치 강제·손상 내성). 일배치 0-d 는 컴플라이언스 스냅샷과 동일 당월 upsert 라
  매일 호출돼도 당월 1건.

  upsert push 제거 시 당월 스냅샷 미기록으로 실패 대조(fails-without-fix).
