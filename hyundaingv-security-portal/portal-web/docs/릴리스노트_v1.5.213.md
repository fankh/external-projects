# 릴리스 노트 — portal-web v1.5.213

특별서약(보안담당자) 담당업무·세부업무 추가입력 흐름에 회귀 e2e 커버리지를 더하고, 이 기능을 미구현으로
잘못 표기한 낡은 주석을 현행화했다. 기능 자체는 이미 구현돼 있었으나(요구사항: "본문내용 외 담당업무,
세부업무내용 등 추가입력"), 필수 입력 필드가 있는 제출 경로가 e2e 로 검증되지 않고 있었다.

## 배경

깊이 감사 이후 잔여 스펙 요건을 정찰하던 중, 특별서약(보안담당자)의 담당업무 추가입력 흐름을 확인했다:
- 기능은 완전 구현 상태 — `signSpecial`(담당업무 필수 캡처), 제출 폼(name=duty 필수 입력), 제출완료 시
  담당업무 표시가 모두 있었다.
- 그러나 e2e 는 특별서약 중 **프로젝트 참여** 서약만 다루고, **보안담당자 담당업무 입력** 경로는
  검증하지 않는 커버리지 공백이 있었다.
- 서약 관리 화면 안내 문구가 "특별서약 화면은 이후 버전"으로 남아, 이미 구현된 기능을 미구현으로
  잘못 안내하고 있었다(코드-문서 불일치).

## 주요 변경

### 회귀 e2e 커버리지 (`scripts/e2e_suite.py`)
`sc_special_pledge_duty` 신규 — 격리 데이터 파일(보안담당자 박정호, 일반서약 완료·특별 미제출)로 특별서약
화면에서 담당업무를 입력·동의·제출하고, 제출완료와 담당업무 표시를 검증한다. 담당업무 저장을 제거하면
단언이 실패함을 대조 확인해(테스트 유효성) 이 테스트가 실제로 담당업무 캡처 경로를 지키는지 보증했다.

### 안내 문구 현행화 (`app/(app)/pledge/manage/page.tsx`)
"특별서약 화면은 이후 버전" → "보안담당자는 보안서약서 제출 화면에서 담당업무·세부업무내용을 추가 입력해
특별서약을 제출한다"로 정정(구현 상태 반영).

## 호환성·영향
- 무회귀: 테스트 추가 + 안내 문구 정정만. 기능·데이터·산식 무변경.
