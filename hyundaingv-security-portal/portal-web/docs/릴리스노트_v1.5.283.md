# 릴리스 노트 — portal-web v1.5.283

**디자인 정제 — 인라인 SVG 아이콘 세트 통일 + 뉴트럴 마감.** 유니코드 글리프·이모지 혼용 아이콘을
하나의 라인 아이콘 패밀리로 통일하고, 남은 vivid 액센트·마케팅 카피·저작권 표기를 그루프웨어 등급으로
정돈한다. 기능 변경은 없고 순수 표현 계층 정비다.

## 배경 — 발견 경위

기존 내비 아이콘은 `▤ ▣ ▦ ▥`(상호 식별 곤란)·`◧ ⊞ ⊟`(기하 글리프)에 색 이모지(`⛑ ⚠ ⏱ 📎 📌`)가
섞여 있었다. 유니코드 글리프는 폰트·OS 별로 두께·너비·색(이모지 프레젠테이션)이 달라져 일관된 아이콘
세트로 읽히지 않는다. 실제 디자이너 검수 기준에서 가장 먼저 지적되는 지점이라, 단일 라인 아이콘 세트로
교체한다. 그 외 나머지(vivid 보라 액센트, 로그인 슬로건, 저작권 부재)도 함께 정돈한다.

## 주요 변경
- `components/chrome/Icon.tsx`(신규): 24×24 viewBox·currentColor·1.75 스트로크 라인 아이콘 세트(~40종).
  장식용 `aria-hidden`(인접 텍스트 라벨이 접근성 이름 제공). 알 수 없는 키는 `list` 로 폴백.
- `components/chrome/menus.ts`: `ico` 를 글리프 문자 → 아이콘 키로 전환. `AppShell` 좌측 내비가 `<Icon>` 렌더.
- 본문 마커도 SVG 로: 첨부 `Clip`(📎)·공지 고정 핀(📌, 대시보드·공지목록) → `clip`·`pin` 아이콘. 결재
  첨부·화면정의서 배지의 하드코딩 📎 포함.
- 액센트 정돈: 도메인 hue 중 vivid 3종(보라 `#6d28d9`·블루 `#1d4ed8`·로즈 `#be123c`)을 나머지 뉴트럴
  토큰과 같은 낮은 채도로 무광화(`#5b5488`·`#345b96`·`#a23a51`). 앱 유일의 '보라' 잔재 제거.
- 마감: 상태바에 저작권 라인(`© {연도} {고객사}`) 추가. 로그인 히어로 카피를 슬로건('통제 평면')·마케팅
  문장에서 평이한 사실 서술로 교체, 영문 키커(Platform/Domains/Foundation) → 한글(구성/도메인/기반).

## 호환성·영향
- 무회귀: 순수 표현 변경. 아이콘은 장식용이라 접근성 이름·테스트 단언(텍스트 라벨 기반)에 영향 없음.
  저작권은 프로필 `customer` 파생(재사용 프레임워크 브랜딩 단일 원천 유지).
