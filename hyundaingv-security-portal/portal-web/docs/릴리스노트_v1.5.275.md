# 릴리스 노트 — portal-web v1.5.275

정책·지침 관리대장에 **담당 재배정**을 더해, 담당 퇴사 시 끊기던 재검토 지연 알림 폐쇄루프를 복구한다.
위험관리대장의 담당 재배정(v1.5.267)과 동형 — 두 ISMS 도메인이 완전한 패리티를 이룬다.

## 배경 — 발견 경위

정책 도메인 독립 적대 검토에서 핵심 결함 클래스는 클린 확인됐고, 한 가지 설계 관찰이 나왔다 — 등록 후
담당(owner)을 바꿀 경로가 없다. 재검토 지연 알림(v1.5.273)은 재직자 교집합으로 퇴사 담당의 유령 독촉을
막는데, 그 이면(담당 퇴사 시 통지 대상 소멸)에 재배정 경로가 없으면 위험관리대장이 겪었던 것과 같은
폐쇄루프 단절이 된다. 위험 재평가 담당 이관(v1.5.267)으로 이미 그 부류를 고쳤으므로, 정책도 동일하게
재배정 경로를 두어 완전한 패리티를 맞춘다.

## 주요 변경
- `app/(app)/compliance/policies/page.tsx` `reviewPolicy`: 재검토 시 담당을 **재직자로만** 이관(`s.people.some`
  통과 시에만 `p.owner` 갱신 — 퇴사자 재지정 불가). 재검토 폼에 담당 select 추가(현 담당 기본, 퇴사 담당도
  선택지에 노출해 재직자로 넘길 수 있게). 주기적 재검토 시 담당을 확인·이관해 폐쇄루프를 유지한다.

## 호환성·영향
- 무회귀: 재검토(최근검토일 리셋)·개정·폐지·삭제 동작 불변, 담당 이관은 재검토 폼 추가 필드(미변경 시 no-op).
  이관은 재직자 대상만 — 퇴사자 재지정으로 새 유령을 만들지 않는다(재검토 지연 알림 재직 교집합 계약 유지).

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · **e2e 105**(신규 sc_policy_reassign).
- `sc_policy_reassign`(격리): 재검토 경과·퇴사 담당 정책을 재검토 폼에서 재직자(이수진)로 이관 → 대장 반영.
  이관 로직 제거 시 여전히 퇴사 담당으로 실패 대조(fails-without-fix). `sc_policy_lifecycle`(재검토 폼 변경) 무회귀.
