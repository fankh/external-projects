# 릴리스 노트 — portal-web v1.5.293

**디자인 정제 — 카드 장식 영문 라벨(eyebrow) 제거.** 전 화면의 카드 상단에 붙던 영문 소문자 eyebrow
(SETTLEMENT·CONTRACTS·OPERATIONS·DELIVERABLES 등, 바로 아래 한글 제목의 영어 번역)를 걷어낸다.
사내 개발팀이 만든 한글 업무 포털에 어울리는, 한글 제목만 남는 절제된 마감으로 정리한다.

## 배경 — 발견 경위

배포 사이트가 사내 개발팀 산출물로 읽히도록 화면별 'AI 티'를 제거하는 작업의 일환. 스크린샷 점검에서
모든 카드가 한글 제목 위에 영문 eyebrow(제목의 영어 번역)를 달고 있어, 중복·장식적이라 템플릿/AI 인상을
줬다. 정보성 없는 영문 eyebrow만 제거하고, 정보를 담은 동적 라벨(양식 개정일자·조회 건수·문서 유형·코드
id 등 한글/데이터)은 유지한다.

## 주요 변경
- `app/(app)/**` 카드 호출부에서 정적 영문 `kicker` 100건 제거(40개 화면). 화면 헤더(ScreenHeader)의
  도메인 kicker(한글 브레드크럼)와 정보성 동적 kicker(양식 개정일자·검색 건수·문서 유형 등)는 유지.
- `components/ui.tsx` `Card` 의 `kicker` 렌더는 유지(동적 정보 라벨용) — 정적 장식 라벨만 호출부에서 제거.
- 게이트 마커 갱신: 재무 리포트 가시성 스코프 검사(smoke)는 카드 eyebrow('Plan vs Actual') 대신 표 헤더
  '기준액'으로, 연동 채널 카드 로케이터(e2e 프로필 스위칭 3건)는 '연동 채널' 한글 제목으로 전환.

## 호환성·영향
- 무회귀: 표현 계층(장식 라벨) 제거. 카드 제목·표·데이터·집계 불변. 접근성·기능 영향 없음.
