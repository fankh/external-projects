# 릴리스 노트 — portal-web v1.5.233

보안담당자 지정/해제(toggleOfficer)에 감사 기록을 더했다. 보안담당자는 특별서약 대상이자 보안 관리 책임을
지는 거버넌스 역할인데, 지정/해제가 감사 로그에 남지 않아 '누가 누구를 보안담당자로 지정했나'를 추적할 수
없던 §VI 이력추적성 갭을 닫는다(재택 대상자 변경·협력업체 서약 징구 감사와 동일 정책).

## 배경 — 발견 경위

협력업체 서약 징구 감사(v1.5.231) 후 관리 액션 감사 커버리지를 체계적으로 훑었다. 설정/관리 화면의 액션은
대부분 감사되나(결재선 변경·메뉴권한 변경·재택 대상자 변경·공통코드 변경 등), pledge/manage의 toggleOfficer
(보안담당자 지정/해제)만 감사가 없었다. securityOfficers는 이름 배열이라 지정자 필드가 없어, 거버넌스 역할
배정의 이력이 전무했다. (settings/menus uploadSpec은 스펙 문서 첨부라 감사 대상 아님 — 확인.)

## 주요 변경
- `lib/audit.ts`: AuditAction에 '보안담당자 지정' 추가.
- `app/(app)/settings/audit/page.tsx`: ACTION_TONE(strict Record<AuditAction>) 매핑 추가.
- `app/(app)/pledge/manage/page.tsx` `toggleOfficer`: 행위자 포착 + `audit(행위자, '보안담당자 지정', 대상·지정/해제)`.
  지정·해제를 detail로 구분 기록.

## 호환성·영향
- 무회귀: 감사 로그 1종 추가. 지정/해제 동작·특별서약 대상 산정 무변경.
