# 릴리스 노트 — portal-web v1.5.225

협력업체서약서 징구(addCompanyPledge)에 이중 징구 방어 가드를 더했다. v1.5.223(인프라변경 이중 등록 방어)에
이어, 같은 더블클릭 중복생성 클래스를 등록 액션 전반으로 정합화하는 후속이다.

## 배경 — 발견 경위

인프라변경 이중 등록 방어(v1.5.223) 후 워크플로 진입형 등록 액션의 dedup 가드 유무를 sibling 대조했다.
addCompanyPledge는 서버액션 폼 더블클릭 시 같은 협력업체·대상자의 등록 건이 두 벌 생겨, 둘 다 결재상신
후보(선택 체크박스)로 노출되고 상신 시 같은 인원에 대한 결재가 이중 생성되는 데이터 중복이 있었다.
(addViolation·addIncident·addReview 는 같은 주체의 복수 건이 정당할 수 있어 제외 — 이중징구가 결코
정당하지 않은 협력업체 서약만 대상.)

## 주요 변경
- `app/(app)/pledge/manage/page.tsx` `addCompanyPledge`: 같은 업체·대상자의 미상신(등록) 건이 이미 있으면
  직전 제출의 중복으로 보고 무시하는 가드 추가(addInfraChange·createSr 와 동일 패턴 — 상신 후[결재중]엔
  재등록 허용, 등록 상태 중복만 차단).

## 호환성·영향
- 무회귀: 이중 징구만 차단. 서로 다른 업체·대상자, 상신 완료 후 같은 인원 재징구는 영향 없음.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · **e2e 87**(기존
  sc_company_pledge 시나리오에 이중 징구 단언 추가 — 시나리오 수 불변).
- `sc_company_pledge` 확장: 같은 업체·대상자를 재등록해도 목록에 1건만 유지됨을 검증. 가드 제거 시 2건이
  생겨 단언이 실패함을 대조 확인(테스트 유효성).
