# 데모 시나리오 — 15분 시연 대본

권한그룹 3계정을 차례로 오가며, 하나의 업무가 신청 → 결재 → 처리 → 집계로 이어지는
폐쇄 루프와 연동 프레임워크를 보여준다. 데모 데이터는 서버 기동 시 시드로 초기화되므로
시연 전 서버를 새로 띄우면 항상 같은 출발점에서 시작한다.

## 준비

`npm run build && npm run start` 후 로그인 화면에서 계정을 고른다. 시연 중 계정 전환은
로그아웃 없이 로그인 화면으로 돌아가 다른 계정을 누르면 된다.

## 1부 — 사용자 김현우 (4분): 셀프서비스와 신청

1. **개인별현황** — 나의 할일 2건(서약서·교육), 보안서약서 '미제출', 관리대상 현황
   2행(재택 미제출·교육 미이수)을 짚는다. "본인이 해야 할 일이 한 화면에 모인다."
2. **보안서약서 제출** — 서약 조항 확인 후 동의 제출. 대시보드로 돌아가면 '완료'로
   바뀌고 할일이 닫혀 있다. *(폐쇄 루프 1: 제출 → 할일 마감 → 집계 갱신)*
3. **SR 신청** — 데이터 SR을 작성하고 파일을 첨부해 상신. 신청내역에서 결재중 상태와
   첨부 뱃지(📎1)를 확인한다. "본문 첨부가 결재 문서에 그대로 붙는다."

## 2부 — 업무담당 박정호 (6분): 처리와 전사 관리

4. **결재함** — 김현우의 SR이 수신함에 첨부와 함께 와 있다. 문서 제목을 눌러 상세
   (참조 업무 스냅샷·첨부 파일명)를 확인하고 승인하면 SR이 CI배정으로 넘어가고, 내
   '결재' 할일이 자동으로 닫힌다. *(폐쇄 루프 2: 승인 → 상태 전파)*
   시간이 있으면 반려도 보여준다: 사유를 입력해 반려하면 기안자에게 '재상신' 할일이
   생기고(전 문서 유형 공통, 방치하면 일일 안내메일 대상), 신청내역의 재상신 버튼으로
   보완 재상신이 이어진다. 재상신 문서 상세에는 이전 회차의 반려 사유가 표로 함께
   보여 결재자가 보완 내용을 심사할 수 있다. *(반려 → 재상신 순환)*
5. **CI SR 관리** — 방금 승인된 SR을 배정·착수. SR 관리 화면에서 데이터 SR은
   '처리중→완료 직행', 시스템개발 SR은 '테스트 처리' 버튼인 것을 비교해 보여준다.
   "유형별 처리 절차가 요구사항 그대로다." 같은 화면 아래 **결재 없는 직접 접수**
   (보안/업무 구분, 접수→처리중→완료 이력)도 한 줄 언급한다.
6. **장애관리** — 신규 장애를 등록(등급은 공통코드에서 온다)하고 조치 후, 조치완료
   건들을 체크해 장애보고 상신. "엑셀양식 자동첨부로 결재가 올라간다."
   시간이 남으면 **랙 · H/W 관리**의 랙구성도를 잠깐 띄운다 — "랙 → H/W → 서버 →
   시스템 → 배치·인터페이스가 등록 데이터 그대로 도식이 된다."
7. **부서 서약 현황** — 미서약 부서에 안내메일 발송. 상태바의 '마지막 배치'가 즉시
   바뀐다. *(연동 프레임워크: 메일 어댑터 경유, 발송 이력 기록)*
7-1. **보안점검** (시간 여유 시) — 결과 결재상신 후 결재함에서 "이 문서는 **2단 결재**
   (부서장 → 담당부서장)로 흐른다"를 보여준다 — 1차 승인해도 현황판은 결재중 유지,
   2차 승인에서 완료로 집계. "결재선 관리에서 문서 유형별로 1·2차를 지정한다." 

## 3부 — Admin 시스템관리자 (4분): 통제와 연동

8. **연동·인프라** — 채널 구성(실연동 5종 + 연동 예정 2종)과 어댑터 바인딩(portal.config)을 보여주고, 보안·출력물
   채널을 '가동'으로 토글. "고객사 배포는 이 어댑터 교체가 전부다."
9. **출력물 개인정보관리**(박정호로 전환해도 좋다) — 전일자 이관 실행으로 5건이
   들어온다. *(어댑터 실증: 채널이 꺼져 있으면 이관 자체가 실패로 남는다)*
10. **결재선 관리** — 'SR 신청' 결재자를 바꾸면 이후 상신부터 새 결재자에게 간다.
11. **감사 이력** — 방금 한 승인·채널 토글·결재선 변경이 전부 기록되어 있다(엑셀
    다운로드 가능). "통제 행위는 수정·삭제 없는 로그로 남는다." 배치 이력에 '일일 알림
    배치'가 보이면 "스케줄러가 미서약·점검 경과·SR 지연을 자동 안내한다"고 덧붙인다.

## 마무리 (1분)

12. **통합 검색** — 타이틀바에 'ERP'를 치면 SR·계약·장애가 권한 스코핑 그대로 한 화면에
    모인다.
13. **투자 관리** — 계획대비실적의 집행률과 '엑셀 다운로드'를 눌러 CSV를 받는다.
    경영계획 표의 **취합 → 효율화(금액 조정) → 확정** 단계 칩을 한 줄 언급한다.
14. **메뉴권한** — 권한 매트릭스를 띄우고 "화면 숨김이 아니라 서버 가드와 자동 테스트가
    같은 표를 따른다"로 닫는다.

## 자주 나오는 질문

- **데이터가 남나?** 기본은 시드 초기화. `PORTAL_DATA_FILE`(또는 Docker `/data` 볼륨)을
  주면 재시작 후에도 유지된다.
- **결재는 그룹웨어와 어떻게 붙나?** 데모는 내장 결재함이고, 실서비스는 그룹웨어
  전자결재 어댑터로 상신·결과를 연동한다(결재 확인은 그룹웨어에서).
- **다른 고객사 적용 비용은?** `profiles/sample-manufacturer.config.ts`를 열어 프로필
  교체 + 어댑터 구현이 커스터마이징의 전부임을 보여준다.
