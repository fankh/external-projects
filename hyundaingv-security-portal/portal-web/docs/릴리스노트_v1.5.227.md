# 릴리스 노트 — portal-web v1.5.227

보안점검 계획 export(inspection-plans)에 팀장 열을 더했다. v1.5.209에서 점검 진행내역 화면에 팀장 열을
추가했으나 export는 갱신하지 않아, 새로 드러낸 팀장(경과 알림 수신·책임 라인)이 ISMS 감사 산출물(CSV)에는
빠져 있던 화면-export 불일치를 닫는다.

## 배경 — 발견 경위

세션의 11개 신규 기능을 적대 검토(서브에이전트)한 결과, 확정 고·중 결함은 없었고 저심각 갭 1건이 확인됐다:
점검계획 export 컬럼이 `계획번호·점검항목·예정월·점검자·상태·점검결과`로, v1.5.209에서 화면에 더한 팀장
컬럼을 빠뜨렸다. SRLABEL export(v1.5.221)와 같은 클래스 — 화면에 새 컬럼을 더할 때 export를 함께 갱신하지
않으면 감사 산출물이 화면과 어긋난다.

## 주요 변경
- `app/api/export/route.ts` inspection-plans: 헤더에 '팀장' 추가(점검자 다음), 행에 `p.teamLead ?? '-'` 추가.
  이제 점검계획 export가 화면과 같은 컬럼 구성으로, 경과 알림 책임자(팀장)를 엑셀로 감사할 수 있다.

## 호환성·영향
- 무회귀: export 컬럼 1개 추가. 화면·저장·알림 로직 무변경. 팀장 미지정 계획은 '-'로 표기(null 안전).

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · **e2e 87**(기존
  sc_inspection_teamlead 시나리오에 export 팀장 단언 추가 — 시나리오 수 불변).
- `sc_inspection_teamlead` 확장: 격리 데이터의 점검계획(팀장 시스템관리자)이 inspection-plans export CSV에서도
  팀장 열·값으로 나옴을 검증. export를 팀장 열 없이 되돌리면 단언이 실패함을 대조 확인(테스트 유효성).
