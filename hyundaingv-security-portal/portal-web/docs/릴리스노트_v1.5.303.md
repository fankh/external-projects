# 릴리스 노트 — portal-web v1.5.303

**SSO 로그인 진입점 — 로그인 화면 노출.** v1.5.301 로 붙인 SSO 로그인 라우트(/api/sso/login·acs)를 로그인
화면에서 실제로 시작할 수 있는 'SSO 로그인' 버튼을 추가한다. 실 SSO 채널이 가동된 배포(샘플 고객사
프로필)에서만 노출하고, 데모 기본(목업 SSO)은 계정 선택 로그인만 유지한다.

## 배경 — 발견 경위

v1.5.301 에서 SSO 어댑터·ACS·login 라우트를 구현했으나, 로그인 화면에 진입점이 없어 실 배포에서
사용자가 SSO 로그인을 시작할 방법이 없었다(라우트가 UI 상 도달 불가). 진입점을 노출해 SSO 연동을 완결한다.

## 주요 변경
- `lib/integrations/registry.ts` `ssoLoginAvailable()`: SSO 채널 가동 + 실 어댑터(목업 제외)일 때만 true.
- `app/login/page.tsx`: `ssoLoginAvailable()` 시 'SSO 로그인 →' 버튼(→ `/api/sso/login`) 노출. 데모 기본
  (mock-sso)은 미노출(계정 선택 로그인 유지). 로그인 카드의 영문 장식 kicker('SAML SSO — Sign in') 제거(디자인 정제).

## 호환성·영향
- 무회귀: 데모 기본 프로필은 진입점 미노출(기존 계정 선택 로그인 불변). 실 SSO 프로필에서만 버튼 추가.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt(41/41) · keycheck · health(51) · **e2e 114**.
- `sc_sso_saml`(금융 프로필): 로그인 화면에 SSO 로그인 진입점(href `/api/sso/login`) 노출 확인 + 기존 서명
  검증 로그인 흐름. smoke(데모 기본): 목업 SSO 프로필 로그인 화면에 진입점 미노출 확인(실-전용 게이팅 대조).
- Playwright 스크린샷: 금융 프로필 로그인 화면 — SSO 로그인 버튼 배치·계정 선택과의 조화 육안 확인.
