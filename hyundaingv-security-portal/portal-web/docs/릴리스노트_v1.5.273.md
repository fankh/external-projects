# 릴리스 노트 — portal-web v1.5.273

정책·지침 관리대장(v1.5.271)의 **폐쇄 루프를 완성**한다. 일일 알림 배치에 8번째 유형 '정책 재검토 지연'을
더해 재검토 예정일 경과 정책의 담당에게 안내하고, 경영 대시보드에 '정책 재검토 경과' 신호를 노출한다.
등록·재검토·개정은 있으나 '재검토 놓친 정책'을 담당·리더십에 상기시키는 경로가 없던 갭을 닫는다.

## 배경 — 발견 경위

정책 관리대장(v1.5.271)은 재검토 예정일 경과를 화면에 표시하나, 그 경과를 담당에게 상기시키는 경로가
없었다. 위험관리대장이 조치 지연 알림·대시보드로 폐쇄 루프를 완성한 것(v1.5.261/263)과 동형으로, 정책
재검토 지연도 일배치 알림·대시보드에 편입한다. ISMS 관리체계 1.1 의 '주기적 재검토'는 놓치면 인증 결함이라
담당 독촉·경영 가시성이 핵심이다.

## 주요 변경
- `lib/notify.ts`: 일배치 8) '정책 재검토 지연' — 재검토 예정일 경과(`isReviewOverdue`) 시행 정책의 담당에게
  안내. 재검토·개정하면 자동 제외(경과 해소). **재직자 교집합**으로 담당 퇴사 시 유령 독촉 방지(SR 지연·위험
  조치 지연 등 타 person 알림과 동일 정합).
- `app/(app)/dashboard/page.tsx`: 전사 운영 스냅샷에 '정책 재검토 경과'(err) 타일 추가. `opsVis.policies =
  canSee('/compliance/policies')` 게이트. 값은 `computePolicyKpis`(lib/policy 단일 원천 — 관리대장 KPI 와 정합).

## 호환성·영향
- 무회귀: 기존 7종 알림·대시보드 타일 불변. 신규 알림 유형은 대상 있을 때만 결과에 포함(0명이면 미표기).
  정책 타일은 /compliance/policies 접근 권한자에게만(opsVis 게이트).
