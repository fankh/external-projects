# 릴리스 노트 — portal-web v1.5.307

**SSO/SAML·어댑터 보안 강화 — 적대적 리뷰 후속 조치.** 신규 연동·인증 코드(v1.5.287~305)에 대한 적대적
보안 리뷰에서 확인된 실결함을 fail-closed 로 바로잡는다. SAML 인증 경로의 오픈 리다이렉트·조건 검증
누락·시각 훅 누출과 어댑터 수치 강제변환 엣지를 닫는다.

## 배경 — 발견 경위

SSO/SAML 은 알려진 취약 표면이라, 빠르게 작성한 인증·어댑터 코드를 바이트 흐름까지 적대적으로 재검토했다.
서명/신원 바인딩(XSW·알고리즘 혼동)과 서명·만료 fail-closed 는 견고함을 확인했고, 아래 실결함을 수정한다.

## 주요 변경 (수정)
- **오픈 리다이렉트(RelayState 백슬래시)** — `app/api/sso/acs`: 로그인 후 RelayState 로컬 경로 검증이
  `/\evil` 을 통과시켜 WHATWG URL 이 외부 origin(`http://evil/`)으로 해석하던 우회를 차단한다. 백슬래시·탭·개행
  거부 + 해석 후 origin 자기동일성 확인(fail-closed, 무효 시 `/dashboard`).
- **audience 검증 누락** — `saml.ts`: SP EntityID 미설정 시 audience 검사가 통째로 생략되던 것을, 메타데이터와
  동일 기본값으로 일관화해 어설션에 AudienceRestriction 이 있으면 반드시 우리 SP 와 일치하도록(타 SP 발급
  토큰 재사용 차단).
- **NotBefore 미검증** — `saml.ts`: NotBefore 가 있으면 파싱 불가·도래 전을 거부(미래 유효 어설션 선행 사용 방지).
- **시계 훅 운영 누출** — `saml.ts`: `PORTAL_SAML_NOW`(만료 평가 시각 고정)를 비운영에서만 허용(운영 누출 시
  만료 동결 방지).
- **수치 강제변환 엣지** — `rest.ts` `pickField`: 비유한 수치(NaN·Infinity)를 문자열로 흘리지 않도록 유한성 검사.

## 리뷰가 확인한 견고성 (수정 불요)
- XML Signature Wrapping 없음(NameID·속성·조건을 서명 검증한 동일 바이트에서만 판독) · 알고리즘 혼동 없음
  (RSA-SHA256 하드코딩) · 서명/만료 fail-closed(누락·오형·경과 모두 거부) · ACS 는 검증 성공+계정 매핑 시에만
  세션 발급(우회 분기 없음) · 사용자 입력발 SSRF 없음(URL 은 운영 env) · 시크릿 미로깅 · 채널 게이팅 정확.

## 알려진 배포 구성 주의(코드 아님)
- 세션 쿠키 `Secure` 는 `PORTAL_COOKIE_SECURE=1` 로 켠다(http 데모·게이트 실행 위해 기본 off) — 운영 HTTPS 필수.
- SAML NameID→계정 매핑은 데모 계정표 기준(참조) — 운영은 검증된 프로비저닝 원천으로 교체.
- `SESSION_SECRET` 미설정 시 개발 기본키 폴백(기동 준비검사 경고) — 운영은 반드시 설정.
