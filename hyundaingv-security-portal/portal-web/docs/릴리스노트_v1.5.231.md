# 릴리스 노트 — portal-web v1.5.231

협력업체 서약 징구(addCompanyPledge)에 감사 기록을 더했다. 협력업체 서약 징구는 타 주체(파트너사) 기록을
등록하는 관리 행위인데 레코드에 징구자 필드가 없고 감사 로그도 없어, 공유 워크스페이스에서 '누가 징구했나'를
추적할 수 없던 §VI 이력추적성 갭을 닫는다(v1.5.44 보안위반 등록 감사와 동일 정책).

## 배경 — 발견 경위

감사 커버리지 정합성을 점검하던 중 발견했다. v1.5.44에서 addViolation(타인 위반 등록)이 감사 무기록·등록자
필드 부재로 추적 불가였던 것을 감사 로그로 마감했는데, addCompanyPledge는 같은 클래스(타 주체 기록 등록,
CompanyPledge에 징구자 필드 없음)임에도 감사가 없었다. 협력업체 서약은 공유 워크스페이스(부서담당·업무담당·
Admin)에서 징구·상신되어 징구자와 상신자가 다를 수 있는데, 상신만 '결재 상신'으로 감사돼 최초 징구자가
누락됐다.

## 주요 변경
- `lib/audit.ts`: AuditAction에 '협력업체 서약 징구' 추가.
- `app/(app)/settings/audit/page.tsx`: ACTION_TONE(strict Record<AuditAction>)에 매핑 추가(컴파일러가 톤
  누락을 막는다).
- `app/(app)/pledge/manage/page.tsx` `addCompanyPledge`: `audit(징구자, '협력업체 서약 징구', 번호·업체·대상자)`
  추가.

## 호환성·영향
- 무회귀: 감사 로그 1종 추가. 징구·상신·승인 흐름·데이터 무변경. 기존 감사 소비처(설정>감사)는 새 톤으로 표시.
