# 릴리스 노트 — portal-web v1.5.247

일일 알림 배치의 'SR 지연' 안내메일이 퇴사한 담당 CI에게 유령 독촉을 보내던 결함을 고쳤다. 다른 모든
person 대상 알림(미서약·비일반 재서약·점검 경과·보안성 검토 경과·QnA 미답변·재택 미제출·출력물 미등록·
반려 방치·확인서 미제출)은 수신자를 현재 재직 명단(s.people)과 교집합해 퇴사자 유령 독촉을 막는데,
'SR 지연'만 그 교집합이 빠져 있어 담당 CI(또는 신청자)가 퇴사해도 매일 완료예정일 경과 안내가 발송됐다.

## 배경 — 발견 경위

인사 이탈(퇴사) 경로의 잔존 참조를 점검하다 발견. syncHr(인사 동기화)는 s.people 을 참조 교체로 갱신하는데,
name 기반 참조(securityOfficers·sr.ci 등)는 별개 명단이라 소비처가 재직 교집합으로 걸러야 유령이 안 샌다.
securityOfficers 는 모든 소비처(eligibleForCourse·특별 재서약·보안담당자 집계·칩)가 이미 s.people 과 교집합해
안전했으나, notify 'SR 지연'만 delayedSrs→CI 매핑 뒤 교집합 없이 그대로 발송해, 이 계열 하드닝(미서약·재택·
점검 v1.5.67·90 등)에서 유일하게 누락돼 있었다.

## 주요 변경
- `lib/notify.ts` 'SR 지연' 안내: 수신자(`delayedSrs → r.ci ?? r.requester`)에 재직 교집합
  `.filter((name) => people.some((p) => p.name === name))` 추가. 타 person 알림과 동일 정책. CI 퇴사 시 신청자
  폴백 없이 드롭(sibling 경로와 동일 — 지연 SR 은 sr/delayed 화면에 남아 관리자 재배정·가시성 유지).

## 호환성·영향
- 무회귀: 재직 CI 의 지연 SR 알림은 그대로. 퇴사 CI(또는 신청자)만 수신자에서 제외돼 유령 독촉이 사라진다.
- 지연 SR 자체는 지연내역 화면·대시보드·export 에 그대로 노출 — 재배정 가시성 유지.
