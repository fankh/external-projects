# 릴리스 노트 — portal-web v1.5.175

이 릴리스는 장애관리의 **월별 통계표를 산출물로** 꺼낸다. 지금까지 발생월 × 등급 장애 통계는 화면에서
렌더링되기만 했고, 장애 export 는 원시 대장(건별)뿐이었다. 관리·감사에서 실제로 보고하는 것은 주기별
통계표다(제품안내서 III장). 이제 그 통계표를 엑셀로 내려받고, 산식을 화면과 한 곳에서 공유한다. 전 게이트가
그린이다.

## 주요 변경

### 월별 장애 통계 단일 원천
`lib/infra.ts` `monthlyIncidentStats(s)` 가 발생월 × 등급 집계를 한 곳에서 산출한다. 등급 컬럼은 공통코드
(FAULT_GRADE) 전체 + 실제 장애에 존재하는 등급의 합집합이라, 코드에서 삭제된 등급의 과거 장애도 '계'와
정합한다(등급별 합 = 계). 월은 최신월 우선, 각 월의 전체·조치완료 건수를 함께 낸다.

### 통계표 export·화면 소비
- **월별 장애 통계**(incident-stats) export: 발생월·등급별 건수·계·조치완료. 원시 대장(incidents)과 별도로,
  보고용 통계표를 그대로 엑셀로 받는다.
- 장애관리 화면의 월별 통계 카드가 인라인 집계를 헬퍼 호출로 바꿔(중복 제거), 화면과 export 가 같은 값을 본다.
- 두 export 는 장애관리 화면(`/infra/incidents`)의 담당·Admin 게이트를 따른다 — USER 차단(403).

## 호환성·영향
- 무회귀: 신규 export 로 기존 대장 export·화면 동작 불변. 화면 통계표 수치는 리팩터 전과 동일(같은 술어를
  헬퍼로 이동). 저장 스키마 변경 없음.
