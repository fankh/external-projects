# 릴리스 노트 — portal-web v1.5.120

전사 IT·보안 거버넌스 포털의 v1.5.120 릴리스는 제품안내서 VI장이 규정한 **보안성 검토** 업무를 신규
도메인으로 복원하고, ISMS 외부 감사와 경영 보고에 쓰는 **종합 현황 산출물**을 더한 트랙이다. 요구사항
100% 구현이 확인된 뒤에도 안내서가 목적으로 명시한 지점(감사 근거 확보)을 서비스하는 산출물이 남아
있었고, 이를 프레임워크 전 계층에 정합하게 통합했다. 전 게이트가 그린 상태이며(e2e 68/68), 두 종합
현황 export 는 실행 서버에서 대시보드 수치와 일치함을 실측 검증했다.

## 주요 변경

### 신규 도메인 — 보안성 검토 (시큐어코딩·취약점 점검·자료 제출)
제품안내서 VI장의 미구현 요구를 온전한 도메인으로 구현하고, 포털의 기존 도메인과 같은 깊이로 전 계층에
통합했다.
- 검토 생명주기 화면: 계획 → 진행 → 조치중 → 완료. 발견·조치 취약점 건수와 증적 자료를 기록하며,
  발견을 전건 조치해야 완료로 확정된다(미조치 잔여가 있으면 완료 차단 — 감사 무결성).
- 조치율은 0 나눗셈과 거짓 100%를 방어한다(발견 0건은 '해당없음'으로 표기).
- 전 계층 통합: 엑셀 export, 개인별현황 대시보드의 '미조치 취약점' 신호, 일일 배치의 '착수 예정일 경과'
  안내메일, 통합검색 인덱싱, 감사 로그 액션.

### 감사 근거 종합 현황 산출물
안내서가 명시한 'ISMS 외부 감사 대응 근거'와 경영 보고를 위해, 도메인을 가로지르는 두 종합 현황
export 를 추가했다. 각 지표는 소속 화면의 단일-원천 술어를 그대로 재사용하므로 화면과 수치가 어긋나지
않는다.
- 보안 컴플라이언스 종합 현황: 서약률·교육 이수율·보안점검·보안성 검토 조치율·보안위반을 한 CSV 로
  집계. 보안점검(ISMS) 화면에서 내려받으며 담당·Admin 전용이다.
- IT 운영 종합 현황: SR(진행·지연)·장애(조치중)·프로젝트(진척·이슈)·투자/비용 집행률을 한 CSV 로
  집계. 개인별현황 전사 운영 스냅샷 카드에서 내려받으며 담당·Admin 전용이다.

### 교차 결함 수정
- 감사 로그 액션 색상: 미분류로 남아 무차별 표기되던 4종(보안위반 등록 등)을 색인하고, 매핑을
  `Record<AuditAction>` 로 강제해 신규 액션이 톤 없이 추가되면 빌드 오류로 잡히게 했다.
- 신규 export 레지스트리 편입 결함 2건: 보안성 검토 export 가 런타임 메뉴권한 게이트(EXPORT_MENU)에서
  빠져 정적 검사만 받던 것과, 콘솔·하이드레이션 점검(client_health) 대상에서 누락됐던 것을 각각 편입했다.

## 검증
- 게이트 전량 그린: build · smoke 575 · a11y 697 · emptystate/corrupt 38 · keycheck 3 · health 48 · e2e 68.
- 두 종합 현황 export 는 실행 서버(BIZ_MGR 세션)에서 대시보드와 겹치는 지표가 정확히 일치함을 실측:
  IT운영(조치중 장애·지연 SR·프로젝트 오픈 이슈), 컴플라이언스(미조치 취약점 직접 일치 + 서약 교차 정합).
- 접근 통제: 두 export 모두 담당·Admin 전용을 smoke 로 실증(BIZ_MGR 200 · USER·DEPT_MGR 403).

## 호환성·영향
- 무회귀: 모든 변경은 기본값 불변의 소단위 커밋으로, 기존 동작을 바꾸지 않는다. 신규 컬렉션(보안성 검토)은
  시드 형판 기반 스토어 정규화가 자동으로 손상 내성을 부여한다.
- 외부 입력 불요: 이번 트랙은 고객사 어댑터·SSO·MS-SQL 없이 구현 가능한 범위만 다뤘다. 잔여 로드맵
  항목(사용자그룹·메뉴기능 관리, 어댑터 실구현)은 종전과 같이 외부 계약·설계 결정에 의존한다.
