# 릴리스 노트 — portal-web v1.5.170

이 릴리스는 프로젝트 거버넌스 데이터를 **화면 밖으로** 꺼낸다. 지금까지 이슈·리스크와 산출물 현황은
일정·산출물·이슈 화면 안에서만 볼 수 있었고, 대시보드는 오픈 이슈 건수만 보였다. PMO·운영위 보고에
필요한 이슈·리스크 대장과 산출물 대장을 엑셀로 내려받고, 대시보드에 높은 리스크 신호를 더했다. 전 게이트가
그린이다.

## 주요 변경

### 프로젝트 PMO 신호 단일 원천
새 `lib/projects.ts` `computeProjectPmo(s)` 가 산출물 완료·기한경과, 오픈 이슈, 높은 리스크(오픈)를 한 곳에서
산출한다. 일정·산출물·이슈 화면과 대시보드가 이 술어를 공유해 수치가 어긋나지 않는다.

### 이슈·리스크·산출물 대장 export
- **이슈·리스크 대장**(project-issues): 번호·프로젝트·이슈·리스크 등급·상태·등록일. PMO/운영위 보고 근거.
- **산출물 대장**(deliverables): 번호·프로젝트·산출물·기한·상태(완료/기한경과/미완). 기한 경과를 상태로 표기.

두 export 는 일정·산출물·이슈 화면(`/projects/schedule`)의 담당·Admin 게이트를 따른다 — USER·DEPT_MGR 는
차단(403). 각 카드에 '엑셀 다운로드' 버튼을 더했다.

### 대시보드 신호
개인별현황 전사 운영 스냅샷에 **프로젝트 높은 리스크** 타일을 더했다. 기존 프로젝트 오픈 이슈 타일도 같은
`computeProjectPmo` 단일 원천에서 산출하도록 바꿔 화면과 정합한다.

## 호환성·영향
- 무회귀: 신규 export·신호로 기존 KPI·동작 불변. 저장 스키마 변경 없음(기존 deliverables·projectIssues 사용).
- 접근 통제: 신규 대장 export 는 화면과 동일 담당·Admin 게이트(smoke 로 200·403 검증).
