# 릴리스 노트 — portal-web v1.5.165

이 릴리스는 IT 투자/비용의 **집행률 산식을 하나로** 모은다. 지금까지 계획 대비 집행률은 투자 화면·비용
화면·IT 운영 종합 현황 export 세 곳에 각각 손으로 유지되는 사본이 있었다. 확정계획 스코프를 어떻게 잡느냐
(계획외·미확정 계약 집행을 넣느냐)를 한 곳만 바꾸면 화면과 산출물이 어긋날 수 있었다. 이제 `lib/finance`
단일 원천이 세 곳을 대신하고, 대시보드에도 집행률을 노출한다. 전 게이트가 그린이다.

## 주요 변경

### 재무 집행 KPI 단일 원천
새 `lib/finance.ts` `computeFinanceKpis(plans, contracts, settlements)` 가 확정계획 합·계약액·집행액·집행률을
한 곳에서 산출한다. 집행률 분자(paidConfirmed)는 분모(확정 계획)와 스코프를 맞춰 계획외·미확정 계약 집행을
제외하므로, 계획대비실적 표의 per-plan 집행률 합과 일치하고 100%를 넘지 않는다. 컬렉션을 인자로 받는
설계라 호출자가 넘긴 배열로 표도 그리고 KPI 도 낸다 — 표와 지표가 같은 데이터를 본다.

### 3중 복제 제거
투자·비용 화면이 각자 인라인으로 갖고 있던 동일한 집행률 블록(−25행)과, IT 운영 종합 export 의 세 번째
사본(local `pct` 포함)을 모두 헬퍼 호출로 바꿨다. 산식이 한 곳에만 있으므로 divergence 여지가 사라졌다.

### 대시보드 노출
개인별현황 전사 운영 스냅샷에 **투자 집행률·비용 집행률** 타일을 더했다. 집행률은 지금까지 export 안에서만
보였다. 이 타일은 전사 집계 수치이므로 개별 재무 화면 접근권(역할 스코프)이 아니라 담당·Admin 관리 시야
(`/sr/manage`)로 게이트한다 — 운영 스냅샷이 USER·DEPT_MGR 에게 노출되지 않는 불변을 지킨다.

## 호환성·영향
- 무회귀: `computeFinanceKpis` 는 종전 3개 사본과 수치가 동일(같은 스코프·산식을 옮겼을 뿐). 저장 스키마 불변.
- 접근 통제: 대시보드 재무 타일은 관리자 게이트로 제한(개발 중 게이트가 USER·DEPT_MGR 노출 회귀를 적발·수정).
