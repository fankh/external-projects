# 릴리스 노트 — portal-web v1.5.277

ISMS **보안 컴플라이언스 종합현황** export 에 정책·지침 관리 라인을 더해, 이 세션에 추가한 두 관리체계
도메인(위험평가·정책관리)이 모두 종합 관리 근거에 반영되도록 완결한다.

## 배경 — 발견 경위

종합현황 export(감사 대응 종합 근거)는 포스처·서약·교육·점검·보안성검토·위반에 더해 위험평가 라인을
포함하나(v1.5.259), 새로 추가한 정책·지침 관리(v1.5.271~) 라인이 빠져 있었다. 관리체계(ISMS) 종합
근거로서 정책 문서의 재검토 현황도 위험과 함께 한눈에 보여야 하므로, 위험 라인과 동형으로 정책 라인을 더한다.

## 주요 변경
- `app/api/export/route.ts` 종합현황(`compliance-summary`): '정책·지침 관리' 라인 추가 — 시행 정책 수/전체,
  재검토 경과·개정중 건수(`computePolicyKpis` 단일 원천). 정책 0건이면 '해당없음'(위험 라인·타 무분모 라인과
  동일 규약).

## 호환성·영향
- 무회귀: 기존 종합현황 라인 불변, 정책 라인 1줄 추가(BIZ 게이트 그대로). 정책 KPI 는 관리대장·대시보드와
  동일 lib/policy 단일 원천이라 수치 정합.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · e2e 105.
- `sc_policy_lifecycle`: 종합현황 export 에 '정책·지침 관리' 재검토 경과 라인(시행 1·경과 1) 포함 단언 추가.
  정책 라인 제거 시 종합현황에서 누락돼 실패 대조(fails-without-fix).
