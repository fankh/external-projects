# 릴리스 노트 — portal-web v1.5.147

이 릴리스는 컴플라이언스 포스처를 **하나의 점수(0~100)**로 요약한다. 서약률·이수율·조치율·점검·고위험
미조치처럼 지표가 여럿이면 경영진이 한눈에 판단하기 어렵다. 이제 다섯 축을 가중 합산한 **포스처 점수**를
화면·대시보드·산출물 전반에 노출하고, 추세 스냅샷과 함께 월별 추이로 본다. 전 게이트가 그린이다(e2e 69/69).

## 주요 변경

### 포스처 점수 산출
`compliancePostureScore`(lib/compliance)가 다섯 축을 각 20점으로 균등 합산한다.
- 서약률·이수율·조치율·점검 완료율은 그대로 점수화(각 백분율/5).
- 리스크 축은 100 에서 고위험 미조치(-10/건)·위반 미완료(-5/건)를 차감한다(하한 0).
- 발견 취약점이 없으면 조치율 축은 만점으로 본다(조치 대상 없음=리스크 없음).
등급은 `postureRating` 으로 양호(90+)·보통(75+)·주의(60+)·미흡으로 나눈다.

### 화면·대시보드·산출물 노출
- 보안점검(ISMS) 화면: 추세 카드 상단에 **현재 포스처 점수** 배너(점수+등급)와, 추세 표에 **점수 열**(전기
  대비 델타)을 더했다.
- 개인별현황 전사 운영 스냅샷: **컴플라이언스 점수** 신호(등급에 따라 색).
- 컴플라이언스 종합 현황 export: 최상단에 포스처 점수 행. 추세 export: 점수 열.

모두 `compliancePostureScore` 단일 원천에서 산출하므로 화면·대시보드·산출물·스냅샷의 점수가 일치한다.

## 호환성·영향
- 무회귀: 점수는 신규 지표로, 기존 KPI·동작을 바꾸지 않는다. 스냅샷에 score field 를 더했고 평면 필드라
  스토어 정규화가 손상 내성을 자동 부여한다(빈·손상 스토어 38/38 렌더 정상).
- 데이터: 시드 스냅샷 2건에 점수(56·65)를 넣어 카드가 즉시 추이를 보인다.
