# 릴리스 노트 — portal-web v1.5.152

이 릴리스는 컴플라이언스 포스처 점수를 **행동으로 바꾼다**. 앞선 릴리스(v1.5.147)가 여러 지표를 하나의
점수로 요약했다면, 이번에는 그 점수를 이루는 **다섯 축을 분해**해 각 축의 현재 수준을 보이고, 점수를 가장
많이 끌어내리는 **최약 축을 개선 우선순위로 지목**한다. "68점"이 아니라 "68점 — 교육 이수율이 최약,
미이수 12건 이수 안내"로 읽힌다. 전 게이트가 그린이다.

## 주요 변경

### 축 분해 — 점수가 곧 다섯 축의 평균
`postureAxes`(lib/compliance)가 포스처 점수를 이루는 5개 축을 각각 산출한다: 서약률·교육 이수율·취약점
조치율·점검 완료율·리스크 관리. 각 축은 원점수(0~100)와 100점 만점 기여분(pct/5), 그리고 개선 행동
안내(예: "미조치 취약점 6건 조치")를 함께 낸다. `compliancePostureScore` 는 이제 이 축들의 평균으로
정의돼(리팩터링, 값은 종전과 동일), 점수와 분해가 **한 원천**에서 나오므로 절대 어긋나지 않는다.
`weakestPostureAxis` 가 가장 낮은 축(개선 우선순위)을 고른다.

### 화면·산출물 노출
- 보안점검(ISMS) 화면: 포스처 배너 아래 **축 분해 패널**을 더했다. 다섯 축을 미니 막대로 보이고(90+ 초록·
  60+ 주황·미만 빨강), 최약 축 칸을 빨강 틴트로 강조한다. 그 아래 **개선 우선순위** 줄이 최약 축과 구체적
  행동 안내를 문장으로 제시한다.
- 컴플라이언스 종합 현황 export: 포스처 점수 행 바로 아래 **개선 우선순위(최약 축)** 행(축·수준·행동 안내).

## 호환성·영향
- 무회귀: `compliancePostureScore` 반환값·시그니처 불변(축 평균 = 종전 공식과 수치 동일). 소비처 전부 무변경.
- 축 분해는 실시간 KPI 로 산출하며 저장 스키마를 바꾸지 않는다(스냅샷 구조 그대로).
