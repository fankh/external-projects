# 릴리스 노트 — portal-web v1.5.281

**재해복구 도메인 폐쇄루프 완성 — 복구훈련 지연 알림 + 대시보드 신호.** v1.5.279 로 신설한 재해복구·업무연속성
관리대장(ISMS 2.12)에 위험·정책 도메인과 동형의 폐쇄루프를 붙인다. 훈련 예정일이 경과한 복구계획을 담당에게
정기 통지(9번째 알림 유형)하고, 전사 운영 스냅샷에 '복구훈련 경과' 타일을 노출한다.

## 배경 — 발견 경위

재해복구 관리대장은 조회·기록은 되나, 훈련 예정일 경과를 **능동적으로 알리는 경로**가 없어 위험·정책 도메인과
비대칭이었다. 위험(위험 조치 지연)·정책(정책 재검토 지연)은 알림 배치·대시보드 타일로 이행을 강제하는데,
재해복구만 수동 조회에 의존했다. 정기 복구훈련 강제(ISMS 2.12)의 실효성을 위해 동일한 폐쇄루프를 붙인다.

## 주요 변경
- `lib/notify.ts` 알림 배치 9번째 유형 `복구훈련 지연`: `isTestOverdue` 로 훈련 예정일 경과 복구계획을 골라
  담당에게 통지. **재직자 교집합**(`people.some`)으로 퇴사 담당 유령 독촉 방지(타 person 경로와 동일 계약).
- `app/(app)/dashboard/page.tsx`: 전사 운영 스냅샷에 `복구훈련 경과` 타일(`computeDrKpis(...).overdue`,
  경과 시 err 톤). `/compliance/dr` 가시성(BIZ) 연동으로 권한자에게만 노출.

## 호환성·영향
- 무회귀: 기존 도메인 집계·화면 불변. 신규 알림 유형은 대상 0명이면 배치 요약에 계상만 되고 발송 없음(멱등).
  대시보드 타일은 단일 원천 `computeDrKpis` 재사용(화면·알림·엑셀 동일 값).
