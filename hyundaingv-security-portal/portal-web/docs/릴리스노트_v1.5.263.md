# 릴리스 노트 — portal-web v1.5.263

정보보호 위험 신호를 **경영 대시보드(전사 운영 스냅샷)**에 노출한다. 위험관리대장(v1.5.259)·조치 지연
알림(v1.5.261)에 이어, 리더십이 착지하는 개인별현황의 운영 스냅샷에 '높음↑ 미종결 위험'·'위험 조치기한
경과'를 더해 위험 가시성을 완성한다(등록 → 조치 독촉 → 경영 대시보드).

## 배경 — 발견 경위

대시보드 '전사 운영 스냅샷'은 이미 컴플라이언스 점수·고위험 미조치 취약점·지연 SR·조치중 장애 등 거버넌스
신호를 화면 유효권한(opsVis)으로 게이트해 노출한다. 위험관리대장의 핵심 신호(높음↑ 미종결·기한 경과)는
정확히 이 카드가 다루는 경영 우선처리 신호라, 같은 게이트·같은 단일 원천(lib/risk)으로 편입해 위험이
전용 화면 밖 리더십 시야에도 드러나게 한다.

## 주요 변경
- `app/(app)/dashboard/page.tsx`: 운영 스냅샷에 '높음↑ 미종결 위험'(≥10 미종결, err) 타일 +
  '위험 조치기한 경과'(경과 건 있을 때만, warn) 타일 추가. `opsVis.risks = canSee('/compliance/risks')`로
  게이트(위험평가 화면 접근 권한자만). 값은 `computeRiskKpis`(lib/risk 단일 원천 — 위험관리대장 KPI·
  종합현황 export 와 정합).

## 호환성·영향
- 무회귀: 기존 타일·집계 불변. 위험 타일은 /compliance/risks 접근 권한자(BIZ_MGR·ADMIN)에게만 노출되며,
  USER·권한 밖 사용자에겐 운영 스냅샷 자체가 안 보인다(기존 opsVis 게이트 동작 동일).

## 검증
- 게이트 전량 그린: build · smoke **600** · a11y · emptystate/corrupt · keycheck · health · e2e 99.
- 스모크: BIZ_MGR 대시보드에 '높음↑ 미종결 위험' 타일 렌더 단언 추가(시드 3건 높음↑ 미종결).
