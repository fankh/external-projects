# 릴리스 노트 — portal-web v1.5.305

**SP SAML 메타데이터 공개 — SAML SP 완결.** IdP 관리자가 신뢰 관계(EntityID·ACS·바인딩)를 구성할 때
임포트하는 SP SAML 메타데이터 엔드포인트(/api/sso/metadata)를 추가한다. 표준 SAML SP 의 필수 요소로,
IdP 연동 설정을 수기가 아닌 메타데이터 임포트로 처리할 수 있게 한다.

## 배경 — 발견 경위

v1.5.301~303 으로 SSO 어댑터·ACS·login·진입점을 갖췄으나, 표준 SAML SP 가 반드시 공개해야 하는 SP
메타데이터가 없어 IdP 측 신뢰 구성을 수기로 해야 했다. 메타데이터 공개로 SAML SP 를 완결한다.

## 주요 변경
- `lib/integrations/saml.ts` `spMetadata(acsUrl)`: SP SAML 메타데이터 XML 생성(EntityDescriptor·SPSSODescriptor·
  AssertionConsumerService·NameIDFormat). EntityID 는 `PORTAL_SAML_SP_ENTITY_ID`, ACS 는 `PORTAL_SAML_SP_ACS_URL`
  (미설정 시 요청 기준 `/api/sso/acs`).
- `app/api/sso/metadata`(신규 라우트): 실 SSO 채널 가동 프로필에서만 메타데이터 공개(데모 목업 프로필은 404 —
  비-SSO 배포에 SP 메타데이터 미노출). Content-Type `application/samlmetadata+xml`.

## 호환성·영향
- 무회귀: 데모 기본 프로필은 404(불변). 실 SSO 프로필에서만 메타데이터 공개. 로그인 진입점 게이팅
  (`ssoLoginAvailable`)과 동일 기준.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt(41/41) · keycheck · health(51) · **e2e 114**.
- `sc_sso_saml`(금융): `/api/sso/metadata` 가 EntityID·ACS·AssertionConsumerService 를 포함한 유효 메타데이터
  공개 확인. smoke(데모): 목업 SSO 프로필은 404 대조.
