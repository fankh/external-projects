# 릴리스 노트 — portal-web v1.5.285

**Pretendard 자체 호스팅(next/font/local).** 그동안 `Pretendard Variable` 을 폰트 스택으로 참조만 하고
번들하지 않아, Pretendard 미설치 클라이언트에서는 Malgun Gothic 으로 폴백돼 타이포가 달라졌다. 가변
폰트를 앱에 번들해 클라이언트 설치 여부와 무관하게 동일한 타이포를 보장한다.

## 배경 — 발견 경위

v1.5.283 디자인 정제 시 감사에서 확인된 잔여 갭: 폰트 스택 1순위가 `Pretendard Variable` 이지만
`@font-face`·`next/font`·번들 파일이 없어 실제로는 OS 설치 폰트에 의존했다. 배포 환경(온프레미스
사내 PC)마다 Pretendard 설치 여부가 달라 렌더 편차가 생기므로, 자체 호스팅으로 고정한다.

## 주요 변경
- `app/fonts/PretendardVariable.woff2`(신규, 가변 폰트 2.0MB) 번들.
- `app/layout.tsx`: `next/font/local` 로 로드 — `weight: '45 920'`(가변 축), `display: 'swap'`,
  `variable: '--font-pretendard'`, 폴백 `Malgun Gothic → Segoe UI → system-ui`. `<html>` 에 변수 클래스 적용.
- `app/globals.css`: `body` 폰트 패밀리 1순위를 `var(--font-pretendard, 'Pretendard Variable')` 로 —
  변수 미주입 경로(자체 `<html>` 렌더하는 global-error 등)에서도 폴백 체인이 유효하도록 in-var 폴백 지정.

## 호환성·영향
- 무회귀: 표현 계층(폰트 자산) 추가. DOM·텍스트·집계 불변. next/font 가 빌드시 서브셋·프리로드 처리,
  woff2 는 해시·불변 캐시로 서빙.

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt(41/41) · keycheck · health(51) · e2e 107.
- 런타임 확인(Playwright): `<html>` 에 next/font 변수 클래스 적용, 계산된 `body` font-family 가
  `--font-pretendard`(생성 패밀리) 해석, **woff2 실제 요청·서빙 확인**(앱 서빙, 클라이언트 설치 무의존).
