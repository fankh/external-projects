# 릴리스 노트 — portal-web v1.5.267

정보보호 위험평가 도메인의 독립 적대 검토(신규 코드 재검토)에서 나온 두 결함을 수정한다.
(1) 위험 담당 재배정 경로를 추가해 담당 퇴사 시 끊기던 조치 지연 폐쇄루프를 복구하고,
(2) 빈 위험 대장의 종합현황 export 를 '해당없음'으로 맞춰 감사 오독을 없앤다.

## 배경 — 발견 경위

위험평가 도메인(v1.5.259~265)을 별도 검토자(신규 코드 적대 검토)로 재감사해 발견.

- **F1(중간): 담당 immutable → 퇴사 담당 위험 폐쇄루프 단절.** `reassessRisk` 는 발생가능성·영향도·처리·
  기한만 바꾸고 **담당(owner)은 바꾸지 못했다**. 담당이 퇴사(syncHr 로 s.people 에서 제거)하면 조치 지연
  알림의 재직 교집합이 그를 건너뛰어(유령 독촉 방지의 이면) 아무도 통지받지 못하는데, 미종결이라 삭제도
  막혀(v1.5.265 가드) 위험이 살아있는 담당에게 넘어갈 in-app 경로가 없었다. 협력업체 결재 폐쇄루프 커버리지
  결함과 같은 부류.
- **F2(낮음): 빈 위험 대장 종합현황 0% 오표기.** 위험이 0건이면 `computeRiskKpis.treatedRate` 가 0 을 반환해,
  종합현황 export 가 '종결률 0% (0/0)'로 찍혔다. 같은 export 의 다른 무분모 라인(이수율·조치율)은 '해당없음'을
  쓰는데 위험 라인만 어긋나, 감사자가 '위험 미조치'로 오독할 소지.

## 주요 변경
- `app/(app)/compliance/risks/page.tsx`: 재평가 폼에 담당 select 추가 + `reassessRisk` 가 **재직자로만** 담당을
  이관(`s.people.some` 통과 시에만 `r.owner` 갱신 — 퇴사자 재지정 불가, no-op). 이관 시 감사에 담당 남김.
  담당 퇴사 위험을 살아있는 담당에게 넘겨 조치 지연 알림 폐쇄루프를 복구한다.
- `app/api/export/route.ts`: 종합현황 위험 라인을 `rk.total > 0 ? '종결률 …%' : '해당없음'`으로 — 무분모 시
  '해당없음'(이수율·조치율 라인과 정합, 0% 오독 방지).

## 호환성·영향
- 무회귀: 기존 재평가(L·I·처리·기한·계획) 동작 불변, 담당 이관은 추가 필드. 위험 있는 종합현황 라인 불변.
- 담당 이관은 재직자 대상만 — 퇴사자 재지정으로 새 유령을 만들지 않는다(재직 교집합 알림 계약 유지).

## 검증
- 게이트 전량 그린: build · smoke · a11y · emptystate/corrupt · keycheck · health · **e2e 101**(신규 sc_risk_reassign).
- `sc_risk_reassign`(격리): 지연 위험 2건(재직·퇴사 담당)에서 퇴사 담당 위험을 재직자(이수진)로 이관 → 대장
  반영 + 알림 '위험 조치 지연 2명'(폐쇄루프 복구). 이관 제거 시 '1명'으로 실패 대조(fails-without-fix).
- `sc_risk_register`: 빈 대장 종합현황 export 가 '해당없음'임을 단언. 조건 제거 시 '종결률 0%'로 실패 대조.
