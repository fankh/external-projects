## 기준

- 양식은 `cupia-ai-research/docs/reference/05_견적서_표준양식_씨커스.xlsx` 의
  `견적서(업무)` 시트(모듈별 정액 산정)를 따랐습니다. 표제부 · 색상 · 테두리 · 비고란
  구성은 표준 양식과 동일합니다.
- 제품(모듈) 단위 정액 견적이므로 재경비 · 기술료는 적용하지 않고 0원으로 두었습니다.
- 기능 내역은 `kita-ax/AI_GUARDRAIL_PROPOSAL.md`, `kita-ax/KT_DS_TALKING_POINTS.md`,
  `bnk-kyra-poc/PoC 수행계획_BNK.md` 에 정리된 KYRA AI Guardrail 기능 범위를 근거로
  RFI 요건에 매핑하였으며, 항목별 대응 요건은 견적서 비고란에 표기하였습니다.

## 재생성 방법

```bash
python build_estimate.py
```

## 확인이 필요한 사항

- **수신처** — 요청 메일 발신 주소가 `junh.park@kt.com` 이어서, 견적서 수신처는
  `케이티디에스(주)` 로 기재하였습니다. 실제 계약 주체가 ㈜케이티인 경우
  `build_estimate.py` 의 `B4` 셀 문구를 수정해야 합니다.
- **견적 범위** — 서버 · 스토리지 등 하드웨어, 상용 LLM API 사용료, 타사 솔루션
  라이선스 비용은 견적에서 제외하였습니다.
