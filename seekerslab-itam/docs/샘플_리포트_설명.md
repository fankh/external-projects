# 샘플 산출물 — AI 리포트 자동 생성 8종

`itam-web`의 **AI 인텔리전스 › 리포트 자동 생성** 화면에서 실제로 생성해 내려받은 결재 첨부용
산출물이다. 손으로 작성한 예시 문서가 아니라, 실행 중인 플랫폼이 자산 대장·발견 저장소·계약·
권한·정책·감사 로그를 읽어 만든 결과물을 그대로 저장한 것.

각 리포트는 **문서(Markdown)** 와 **엑셀 호환 CSV(UTF-8 BOM)** 두 형식으로 저장했다.

## 생성 방법

```
AI 인텔리전스 › 리포트 자동 생성 → 원하는 리포트 행의 [생성]
                                → [엑셀(CSV)] 또는 [문서] 다운로드
```

다운로드 라우트(`/api/reports/[id]`)에는 권한 가드가 있어 사용자 권한그룹은 403을 받는다.

## 수치의 출처

표 항목은 `lib/reports.ts`가 스토어 데이터에서 결정적으로 산출하므로 화면 데이터와 항상
일치한다. 맨 위 요약 서술만 AI가 그 표를 근거로 작성하며, `ANTHROPIC_API_KEY`가 없으면
규칙 기반 서술로 대체된다 — 이 샘플들의 머리말 `규칙 생성`이 그 경우다. 키가 설정되면
동일한 표 위에 LLM이 작성한 서술이 얹히고 머리말이 `AI 생성`으로 바뀐다.

> 데모 스토어(시드 데이터) 기준이므로 계정·자산 정보는 실제 조직 정보가 아니다.
> 생성일은 플랫폼 기준일(`lib/dates.ts`의 `TODAY`)을 따른다.
