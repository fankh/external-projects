# 샘플 산출물 — 감사 대응 자료

`itam-web`의 **AI 인텔리전스 › 리포트 자동 생성** 화면에서 실제로 생성해 내려받은 결재 첨부용
산출물이다. 손으로 작성한 예시 문서가 아니라, 실행 중인 플랫폼이 자산 대장·권한·정책·감사
로그를 읽어 만든 결과물을 그대로 저장한 것.

| 파일 | 형식 | 용도 |
|---|---|---|
| `샘플_감사대응자료.md` | Markdown | 결재 첨부용 문서 |
| `샘플_감사대응자료.csv` | CSV (UTF-8 BOM) | 엑셀에서 바로 열리는 표 형식 |

## 생성 방법

```
AI 인텔리전스 › 리포트 자동 생성 → "감사 대응 자료" 행의 [생성] → [엑셀(CSV)] / [문서] 다운로드
```

리포트는 5종(주간 Shadow IT 브리핑 · 월간 자산 현황 · 라이선스 컴플라이언스 · 재물조사 결과
요약 · 감사 대응 자료)이며, 이 샘플은 그중 하나다.

## 문서에 담기는 것

- **권한 통제 현황** — 계정별 권한그룹·MFA 적용 (환경설정 › 사용자·결재선 기준)
- **필수 결재 지정 화면** — 폐기·편입·격리·차이 조정의 결재선
- **탐지 정책 이행** — 6개 탐지 채널의 대역·시간대·강도 (환경설정 › 탐지 채널·정책 기준)
- **감사 로그** — 권한 밖 접근 시도, AI 질의(권한 필터 적용), 정책 변경 이력

## 수치의 출처

표 항목은 `lib/reports.ts`가 스토어 데이터에서 결정적으로 산출하므로 화면 데이터와 항상
일치한다. 맨 위 요약 서술만 AI가 그 표를 근거로 작성하며, `ANTHROPIC_API_KEY`가 없으면
규칙 기반 서술로 대체된다 — 이 샘플의 머리말 `규칙 생성`이 그 경우다.

> 데모 스토어(시드 데이터) 기준이므로 계정·자산 정보는 실제 조직 정보가 아니다.
